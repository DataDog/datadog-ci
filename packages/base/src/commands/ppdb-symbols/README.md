# Portable PDB Symbols

Upload .NET MAUI Portable PDB files to Datadog to symbolicate your .NET MAUI managed (C#) exceptions.

## Setup

You need to set the `DATADOG_API_KEY` environment variable, or add it to your `datadog-ci.json` file with the `apiKey` field.

Additional environment variable available:

| Environment Variable | Description                                                                                                                     |
|-----------------------|-----------------------------------------------------------------------------------------------------------------------------------|
| `DATADOG_API_KEY`     | (Required) The API key used to authenticate the requests.                                                                        |
| `DD_SITE`             | The Datadog site to upload the symbols to, e.g. `datadoghq.com`, `datadoghq.eu`, etc. Defaults to `datadoghq.com`.                |

## Commands

### `upload`

Use the `upload` command to upload your Portable PDB symbol files to Datadog.

```bash
datadog-ci ppdb-symbols upload <location> --debug-id-manifest <path>
```

- `<location>` (required, variadic): one or more directories or file paths. Directories are scanned recursively for `.pdb` files.
- The command reads the build-time debug ID manifest (generated by `dd-sdk-maui`) to match each `.pdb` file on disk to the debug ID embedded in the corresponding assembly, so the backend can correlate a crash's debug ID with the correct symbol file.

| Parameter                 | Condition | Description                                                                                                                                                                         |
|----------------------------|-----------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| `--debug-id-manifest`      | Required  | Path to the debug ID manifest JSON file (e.g. `dd_debug_ids.json`), mapping each assembly name to its hex-encoded debug ID (PE debug-directory CodeView GUID + Stamp).              |
| `--dry-run`                | Optional  | Runs the command without the final upload step. All other checks are performed. Defaults to `false`.                                                                                |
| `--max-concurrency`        | Optional  | The number of concurrent upload requests to the API. Defaults to `20`.                                                                                                               |
| `--repository-url`         | Optional  | Overrides the remote repository URL used for git metadata, instead of the one derived from the local `.git` directory.                                                              |
| `--disable-git`            | Optional  | Disables the collection of git metadata (repository URL, commit hash) for the uploaded files. Defaults to `false`.                                                                  |
| `--replace-existing`       | Optional  | Forces overwriting existing debug info that has the same debug ID. Defaults to `false`.                                                                                              |
| `--config`                 | Optional  | Path to a `datadog-ci.json` config file, as described in [Configuration][1]. Defaults to `datadog-ci.json` in the current directory.                                                |
| `--fips`                   | Optional  | Enables FIPS mode. See [FIPS support][2].                                                                                                                                             |
| `--fips-ignore-error`      | Optional  | Ignores errors related to FIPS mode. See [FIPS support][2].                                                                                                                           |

#### PDB-to-manifest matching

Each `.pdb` file found under `<location>` is matched to the debug ID manifest by assembly name:

- A `.pdb` file with **no matching entry** in the manifest is skipped, with a warning — it is not uploaded.
- If the manifest contains **two entries whose names differ only by case** and they map to **different debug IDs**, the upload fails with an ambiguous-entry error rather than guessing which one applies.

[1]: https://github.com/DataDog/datadog-ci#configuration
[2]: https://github.com/DataDog/datadog-ci#fips-support
